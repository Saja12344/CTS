# Realistic Remotion Components

Use alongside **remotion-motion-studio** whenever building frames that show UI, product, brand, or lifestyle visuals.

Goal: the video must look **shipped by a real design team**, not generated by a default AI template.

---

## Search order (do not skip)

1. MagicPath `search_components` with concrete queries (product name, UI type: dashboard, pricing, editor, chat, analytics, onboarding).
2. User’s own MagicPath projects / selection / active canvas.
3. Existing repo components (design system; shadcn only as structure — restyle to brand).
4. Official product screenshots / docs / marketing pages (capture assets).
5. Only then author original UI — and make it near-real.

Always open/view preview images before choosing a component.

---

## When adapting a ready component into Remotion

- Keep real layout, type scale, spacing, and color tokens.
- Drive states with `frame` (step 0→1→2 at beat times), not clicks.
- Animate with springs; avoid opacity-only fades as the sole motion.
- Replace placeholder copy with real product language.
- Swap stock avatars/logos for brand assets when available.

---

## When creating from scratch (near-real bar)

Must include most of:

- Believable information density (real nav, labels, numbers)
- Consistent 8px spacing rhythm
- Distinct display + body fonts (no Inter/Roboto hero stack)
- One intentional accent; restrained neutrals
- Actual controls (inputs, toggles, tables, charts) not empty cards
- Soft realistic elevation — not neon glow stacks
- Content in the user’s language when the brief is Arabic/localized

Forbidden “AI slop”:

- Purple mesh gradients + centered headline + 3 feature cards
- Fake glassmorphism soup
- Emoji as primary iconography
- Lorem with abstract blobs as the hero
- Identical card grids with generic icons

---

## Reality checks before render

1. If I remove the brand name, does this still look like a specific product category?
2. Would a designer put this in a real launch deck?
3. Are there real screenshots/assets or only generated decoration?
4. Does motion resemble product UI or only text fades?

If any answer is weak → search again or rebuild the hero UI before finishing.
