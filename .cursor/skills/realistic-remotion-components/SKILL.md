# Realistic Remotion Components

Use on **every** video job with **remotion-motion-studio**.

Goal: looks like a real product team shipped it — not AI template slop.

---

## Search order

1. MagicPath `search_components` (dashboard, pricing, editor, chat, analytics, onboarding, product name)
2. User MagicPath projects / selection / active canvas
3. Repo design system (restyle shadcn to brand)
4. Real product screenshots / Screen Studio captures / marketing pages
5. Figma exports when available
6. Only then author near-real UI from scratch

Always view previews before choosing.

**MagicPath role:** UI + brand components. Motion/timeline stays Remotion or HyperFrames.

---

## Adapt into Remotion

- Keep layout, type, spacing, tokens
- Drive states with `frame` on the beat grid
- Springs over opacity-only fades
- Real product copy + brand logos

---

## Near-real bar

Real density · 8px rhythm · distinct display+body fonts · one accent · real controls · soft elevation · localized language when brief is Arabic.

Banned: purple mesh + 3 cards · glassmorphism soup · emoji icons · lorem+blobs · identical icon grids.

---

## Reality checks

1. Without the brand name, does it still look like a specific product category?
2. Would it pass a real launch deck?
3. Real screenshots/capture or only decoration?
4. Product UI motion or only text fades?

Weak answer → search/rebuild before finishing.
