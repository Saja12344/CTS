# Remosion (Remotion)

Blank Remotion template for the remosion project. Lives in `remotion/` so the existing Vite/React site at the repo root is unchanged.

Agent skills are installed under `.agents/skills/` (via `npx remotion skills add`).

## Commands

From this directory:

```console
npm i
npm run dev          # Remotion Studio (http://localhost:3000)
npm run build        # Bundle for rendering
npx remotion render  # Render composition to out/
```

From the repo root:

```console
npm run remotion        # Studio
npm run remotion:build  # Bundle
```
